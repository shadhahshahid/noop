# AltStore source for this fork

This branch holds one file, `source.json`: the AltStore source for the builds of this personal fork
of [NOOP](https://github.com/ryanbr/noop). It is written by the `Custom iPhone build` workflow on the
`custom` branch (`Tools/custom-altstore-source.py`), never by hand.

Source URL: `https://raw.githubusercontent.com/shadhahshahid/noop/altstore/source.json`

These are unofficial builds of one person's fork. Unless this fork is yours, use the official NOOP
source instead.
